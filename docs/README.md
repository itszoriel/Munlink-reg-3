# MunLink documentation

This directory contains the maintained documentation for the current codebase.

| Document | Use it for |
| --- | --- |
| [Architecture](ARCHITECTURE.md) | Application boundaries, core flows, and important implementation rules |
| [Permissions](PERMISSIONS.md) | Role capabilities and geographic scope |
| [Deployment](DEPLOYMENT.md) | Render blueprint, CI-gated deploys, keeping free services awake |
| [Operations](OPERATIONS.md) | Migrations, seeding, workers, maintenance, and health checks |
| [Testing](TESTING.md) | Automated and manual verification |
| [Security](SECURITY.md) | Authentication, privacy, secrets, uploads, and auditing |
| [Design](DESIGN.md) | Shared visual and responsive UI conventions |

Project-wide agent constraints live in [AGENTS.md](../AGENTS.md). Setup and common commands live in the root [README.md](../README.md).

Historical proposals, dated verification reports, generated handouts, and copied third-party documentation are intentionally excluded. Git history is not the place for credentials or environment-specific test evidence.
